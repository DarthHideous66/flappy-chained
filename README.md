To set up, download the Archive zip file and unzip it. In it you will see an Archive folder. Open up that folder in any Python environment (such as VS code, Pycharm, etc) and make sure you have the latest python installed and pygame. To install pygame if you are on anything but windows, type "pip3 install pygame" in the terminal. If you are on windows type "pip install pygame" (of course without the quotation marks). The controls for the white bird are, W is to jump, A is to move left, and D is to move right. For the blue bird the controls are arrow keys up to jump, left to move left, and right to move right. To pause the game, simply press p.
